# XP Percentage Mod (NeoForge 1.21.1)

A lightweight Minecraft mod that displays your experience progress accurately as a percentage.

## Features
- Displays precise XP percentage on the HUD.
- Built for Minecraft 1.21.1 using NeoForge.

## Building from Source
Clone the repository and build using Gradle:
```cmd
git clone [https://github.com/CANONN-PROD/xppercent.git](https://github.com/CANONN-PROD/xppercent.git)
cd xppercent
gradlew build
